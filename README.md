# Who is Human? · 谁是人类？

> 反向图灵测试 × 群聊狼人杀：一群 AI 混进聊天群伪装人类，玩家要在每轮投票中把它们找出来——同时抵挡 AI 们"你才是 AI 吧"的指控。

## 游戏概念

- 一局 8 人左右：1 名玩家（唯一的人类）+ 7 个带独立 persona 的 AI，同处一个聊天群。
- 所有人的目标都是**显得像人类**：AI 要抹掉"太完美、太礼貌、太爱端水"的马脚；玩家要顶住被指控时的自证压力。
- 每轮流程：自由聊天 → 讨论指控 → 投票放逐 1 人并揭示身份。
- 胜负：玩家在自身不被放逐的前提下找出所有 AI 即获胜；被放逐则进入旁观结局，看 AI 互相残杀。

## 核心设计要点

| 模块 | 设计 |
| --- | --- |
| 马脚旋钮（难度） | 低难度 AI 标点完美、爱总结、什么话题都"两方面看"；高难度 AI 会打错字、有脾气、立场偏激、记性出错 |
| 怀疑值系统 | 每个角色持有一张对所有人的隐藏怀疑值表，随发言动态变化，决定投票倾向（参考《Gnosia》） |
| 人类暴露题 | 每轮话题刻意设计成人类易答、AI 易露馅：童年糗事、冷门偏见、讲笑话、吵架 |
| 试探道具 | 玩家有限次技能：让全员描述昨晚吃了什么，隔两轮突然追问细节抓矛盾 |
| 时序拟人 | 打字延迟随消息长度浮动、"正在输入…"后撤回等廉价人类感来源 |

## 技术形态（原型）

一个周末可完成的最小原型：

- **前端**：群聊 UI（消息流 + 投票面板）
- **后端**：N 个带独立 persona 的 LLM 调用 + 投票状态机
- **关键提示词约束**：AI 绝不承认自己是 AI；系统提示压死"AI 自觉"；发言风格按难度分级注入

## 项目结构

```
who-is-human/
├── server/            # 零依赖 Node.js 后端（node server/index.js 即可运行）
│   ├── index.js       # HTTP 服务：静态页面 + 游戏 API
│   ├── game.js        # 状态机：聊天→投票→放逐→下一轮→终局；时序拟人调度
│   ├── personas.js    # 5 个 AI 群友人设 + 难度分级风格 + 每轮话题（人类暴露题）
│   ├── prompts.js     # 提示词：伪装发言 / 投票决策 / 质询应答（含"绝不承认是AI"铁律）
│   └── llm.js         # OpenAI 兼容客户端 + mock 引擎（无 key 可玩）
├── public/            # 前端：群聊 UI（消息流 / 打字指示 / 唱票动画 / 质询弹窗 / 结算）
├── scripts/
│   └── e2e.mjs        # 端到端流程验证脚本（22 项断言全通过）
├── games/             # 对局留档（gitignore）：每局一份 JSON + 可读 Markdown，每轮结算即写入
└── README.md
```

## 运行

```bash
# mock 模式（无需任何 API key，AI 发言为内置脚本，用于体验流程）
node server/index.js          # 打开 http://localhost:3690

# 接入真实 LLM（任意 OpenAI 兼容接口：OpenRouter / DeepSeek / GLM / Kimi / OpenAI …）
# 方式一：cp .env.example .env 后填入配置（.env 不入库）
# 方式二：环境变量
LLM_BASE_URL=https://openrouter.ai/api/v1 \
LLM_API_KEY=sk-xxx \
LLM_MODEL=deepseek/deepseek-v4.1-flash \
node server/index.js

# 快速跑通整局流程的自动化验证（延迟×0.2 加速）
MOCK=1 TIMESCALE=0.2 node server/index.js &
node scripts/e2e.mjs
```

环境变量速查：

| 变量 | 作用 | 默认 |
| --- | --- | --- |
| `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` | OpenAI 兼容接口三件套，可写入 `.env`（见 `.env.example`），缺一则进 mock | 空 |
| `MOCK=1` | 强制 mock 模式 | 自动 |
| `TIMESCALE` | 全局延迟缩放（测试提速） | 1 |
| `PORT` | 端口 | 3690 |

> 接 OpenRouter 时自动对推理模型关闭思考（`reasoning.enabled=false`），保证群聊回复快、token 省。

## 游戏规则（当前实现）

- 6 人局：1 玩家 + 5 AI（每局从人设库随机抽取）；难度三档对应不同伪装水平；可开关「AI 深度思考」——开=发言前先思考，回复更慢更像人、投票理由更扎实，token 约多一倍（默认开）。
- 每轮：话题闲聊（AI 带打字延迟、撤回等拟人时序）→ 玩家发起投票 → AI 各自投票（唱票逐条亮出+理由，玩家压轴）→ 最高票放逐并揭示身份；平票无人出局，连续两轮平票则抽签放逐。
- 玩家有 2 次「质询」：点名某群友立刻回答问题——AI 作答时看不到自己的历史发言，答非所问或前后矛盾就是马脚。
- 玩家被放逐 → AI 胜；找出全部 AI → 人类胜，终局全员亮身份。
- 局内右上角「退出」可随时回大厅（两段确认，在途 AI 调用自动作废）；大厅下方「历史对局」可在线查看（`/games/xxx.md`）或删除任意一局的记录（JSON+MD 一起删）。
- 每局自动留档到 `games/`（JSON+Markdown，含每轮聊天、逐票理由），复盘伪装效果用。
